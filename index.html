A friendly, step-by-step guide to setting up Claude Code — even if you've never coded before.

Before you start

You'll need these four things. Check them off as you go — your progress is saved automatically.

1

Set up your accounts ✓

About 10 minutes
1

Make a GitHub account

Think of GitHub like Dropbox for code — a place online where your projects live so you don't lose them, and so you can share them.

Open github.com/signup →

Pick a username (this will be public — many people use a version of their real name), enter your email, and choose a password. GitHub will email you a code to verify your address.

2

Make a Claude account

Claude is the AI you'll be talking to. Anthropic is the company that makes Claude.

Open console.anthropic.com →

Sign up using your email or Google account. You'll get a verification email — click the link to confirm.

3

Pick a plan and add payment

Claude Code needs a paid plan. There are two ways to pay:

Claude Pro / Max subscription (recommended for most beginners) — a flat monthly fee, with a generous usage limit that resets every few hours. Predictable cost.

API pay-as-you-go — you load credit and pay per use. Cheaper if you only use Claude occasionally, but harder to predict.

💰 What to expect: Plan prices are shown on the Anthropic site when you sign up. Most beginners start with the lower subscription tier and upgrade only if they hit the limits. (Exact prices verified at implementation time — see Task 13.)

Add a payment method, choose your plan, and confirm.

2

Install your tools ✓

About 15 minutes
1

Install VSCode

VSCode is a free code editor from Microsoft. Think of it like Microsoft Word, but for code. It's where you'll talk to Claude.

Open code.visualstudio.com →

Click the big blue "Download for Windows" button. Once the download finishes, double-click the installer and accept the defaults — the only setting worth changing is checking "Add to PATH" if it's not already checked (this lets other tools find VSCode).

Click the big blue "Download Mac Universal" button. Once the .zip finishes downloading, double-click it to unzip. Drag the Visual Studio Code icon into your Applications folder.

2

Install Claude Code

Claude Code is the actual AI assistant that runs inside VSCode. It can read your files, write code, and run commands for you.

Claude Code on Windows needs Node.js first (a tool that lets other programs run). Download and install it from nodejs.org — pick the "LTS" version, run the installer, accept defaults.

Then open PowerShell (press the Windows key, type "PowerShell", press Enter) and paste this command:

npm install -g @anthropic-ai/claude-code

Press Enter. Wait for it to finish (usually under a minute). (Exact install command verified at implementation time — see Task 13.)

Open Terminal (press Cmd+Space, type "Terminal", press Enter). Paste this command:

npm install -g @anthropic-ai/claude-code

If your Mac says "command not found: npm", you need Node.js first. Install it from nodejs.org (pick the "LTS" version), then try the command again. (Exact install command verified at implementation time — see Task 13.)

3

Install the Claude Code VSCode extension

This is the panel inside VSCode where you'll actually chat with Claude.

Open VSCode. On the left sidebar, click the Extensions icon (it looks like four squares). In the search box, type Claude Code. Find the one published by Anthropic and click Install.

4

Sign in

After install, you'll see a Claude icon on the left sidebar — click it to open the Claude Code panel. The panel will prompt you to sign in. Click Sign in; a browser tab opens; sign in with your Anthropic account; the tab closes and the panel says you're connected.

5

Say hello to Claude

In the Claude Code panel, type this and press Enter:

Hello! Can you tell me what you can help with?

You should see Claude reply within a few seconds. Congrats — you're set up.

3

Add superpowers ✓

About 5 minutes
1

What are "skills"?

Skills are expansion packs for Claude. Each one teaches Claude a new way of working — like how to brainstorm before coding, or how to use a real browser to test a website.

You'll install two skill packs now. Both are free.

2

Install superpowers (by Jesse Vincent / "obra")

This adds careful planning, debugging, and code review skills. In the Claude Code panel, paste each of these one at a time:

/plugin marketplace add obra/superpowers-marketplace
/plugin install superpowers@superpowers-marketplace

(Exact commands verified at implementation time — see Task 13.)

3

Install gstack (by Garry Tan)

This adds testing, deployment, and design-review skills — handy when you want Claude to actually try the website it just built. Paste these in the Claude Code panel:

/plugin marketplace add garrytan/gstack
/plugin install gstack@gstack

(Exact commands verified at implementation time — see Task 13.)

4

Try one

In the Claude Code panel, type:

/brainstorm I want to build a small website about my favorite hobby

Claude should now walk you through a structured brainstorming conversation before writing any code. That's superpowers in action.
