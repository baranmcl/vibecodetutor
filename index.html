A friendly, step-by-step guide to setting up Claude Code — even if you've never coded before.

Before you start

You'll need these four things. Check them off as you go — your progress is saved automatically.

1

Set up your accounts ✓

About 10 minutes
1

Make a GitHub account

Think of GitHub like Dropbox for code — a place online where your projects live so you don't lose them, and so you can share them.

Open github.com/signup →

Pick a username (this will be public — many people use a version of their real name), enter your email, and choose a password. GitHub will email you a code to verify your address.

2

Make a Claude account

Claude is the AI you'll be talking to. Anthropic is the company that makes Claude.

Open console.anthropic.com →

Sign up using your email or Google account. You'll get a verification email — click the link to confirm.

3

Pick a plan and add payment

Claude Code needs a paid plan. There are two ways to pay:

Claude Pro / Max subscription (recommended for most beginners) — a flat monthly fee, with a generous usage limit that resets every few hours. Predictable cost.

API pay-as-you-go — you load credit and pay per use. Cheaper if you only use Claude occasionally, but harder to predict.

💰 What to expect: Plan prices are shown on the Anthropic site when you sign up. Most beginners start with the lower subscription tier and upgrade only if they hit the limits. (Exact prices verified at implementation time — see Task 13.)

Add a payment method, choose your plan, and confirm.
